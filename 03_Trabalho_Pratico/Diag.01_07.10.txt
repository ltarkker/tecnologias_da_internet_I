1.
O user escreve o site num browser, exemplo Microsoft Edge, Google Chrome Safari... 
Variando depois da empresa que está por trás desse Browser, essa informação é enviada ao server da Google, Microsft, etc por exemplo,
e é validada se o domínio do site que o user escreveu na search bar existe, se existe depois o server retorna uma resposta certa ao Front End do site e dependendo
se o site é client-side ou server-side, se for client-side envia o pedido validado no server da google à API que está ligada ao site ou aplicação ou se não for uma API pode ser um RP etc
e depois nessa API e no motor (backend) existe outra validação e autenticação perante a DB que está conectada, se o user existir e a pwd estiver certa retorna um OK a API ao front end e 
deixa o user entrar depois do login.
