Glossário de TINT1

HTML
HyperText Markup Language: linguagem de marcação para estruturar páginas Web, com títulos, parágrafos, listas, tabelas e ligações.
URL
Uniform Resource Locator: o endereço que identifica e localiza um recurso na Web, indicando o protocolo, o servidor e o caminho (por exemplo, https://istec-porto.pt).
HTTP
HyperText Transfer Protocol: o protocolo de pedido e resposta que o browser usa para pedir páginas e outros recursos a um servidor Web.

Desafio: como escrever <p> numa página sem criar realmente um parágrafo?

Dica: escreve as entidades &lt; e &gt; em vez dos símbolos, dentro de um elemento code. O browser mostra o texto <p> no ecrã, mas não cria nenhum parágrafo.
